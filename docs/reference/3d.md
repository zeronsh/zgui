# 3D scenes: scene3d, mesh, light, group

A box showing a 3D scene: meshes in metallic-roughness materials, lights and a camera, drawn with depth and 4x multisampling ([zgx-3d](../../crates/zgx-3d), through a [GPU view](../gpu-views.md)). It's sized and styled as any box.

**Where it is.** `zgx-run` has it. A Rust host turns on zgx-script's `scene3d` feature (`zgx-script = { version = "0.1", features = ["scene3d"] }`). It's off by default because it links the renderer (wgpu), which a headless host doesn't otherwise link. Without it, a script calling `ui.scene3d` stops with an error naming the feature.

**When it draws.** A scene draws a frame only when something it reads changes. Each number, vector and colour of its objects is a literal, a state, a function of state or a [binding](anime.md#bindings) (`ui.tween`, `ui.spring`). A literal is set once. Anything else is followed by an effect of its object's own, so:
- a still scene runs no script and draws nothing;
- a spring turning a model steps in Rust, a frame a refresh, with no script per frame.

```luau
ui.scene3d(props: Scene3DProps) -> Node
ui.mesh(props: MeshProps) -> Object3D
ui.light(props: LightProps) -> Object3D
ui.group(props: GroupProps) -> Object3D
```

```luau
local angle = ui.state("angle", 0)
local metal = ui.state("metal", false)

return ui.column {
	gap = 8,
	ui.row {
		gap = 8,
		ui.button { on_click = function() angle:set(angle:get() + 90) end, "Turn" },
		ui.button { on_click = function() metal:set(not metal:get()) end, "Metal" },
	},
	ui.scene3d {
		w = "100%",
		h = 320,
		rounded = 12,
		background = "#10141b",
		camera = { position = { 0, 1.5, 4 }, target = { 0, 0, 0 }, fov = 40 },
		orbit = { auto_rotate = 10 },
		ui.light { kind = "directional", direction = { -0.5, -1, -0.4 }, intensity = 2.5 },
		ui.light { kind = "hemisphere", color = "#8899aa", ground = "#221a14", intensity = 0.6 },
		ui.group {
			position = { 0, 0.2, 0 },
			ui.mesh {
				geometry = "box",
				size = { 1, 1, 1 },
				rotation = { 0, ui.spring(angle), 0 },
				material = {
					color = "#4a90e2",
					metallic = function() return if metal:get() then 1 else 0 end,
					roughness = 0.35,
				},
			},
			ui.mesh { geometry = "sphere", radius = 0.35, position = { 1.3, 0, 0 }, material = { color = "#d9a441", metallic = 1, roughness = 0.3 } },
		},
		ui.mesh { geometry = "plane", size = { 8, 1, 8 }, position = { 0, -0.5, 0 }, material = { color = "#2a313c", roughness = 0.9 } },
	},
}
```

## scene3d

| Option | Type | Default | |
| --- | --- | --- | --- |
| list entries | `Object3D` | none | its objects: `ui.mesh`, `ui.light`, `ui.group` |
| `camera` | `{ fov, position, target }` | 45°, `{ 0, 1.5, 5 }`, the origin | `fov` in degrees top to bottom; each a `Reactive<number>` or `Vec3` |
| `orbit` | `boolean \| { auto_rotate, zoom, pan }` | off | camera controls, as a model viewer's: see [orbit](#orbit) |
| `background` | `Reactive<Color>` | none: transparent | behind the scene; without one, the box's own `bg` shows through |
| `shadows` | `boolean` | `false` | the sun (the first directional light) casts shadows from opaque meshes. Each frame then draws them once more, from the sun, into a 2048 by 2048 depth map (16 MB, kept while shadows are on) |
| `environment` | `"studio" \| "none" \| string \| { src, intensity, rotation }` | `"studio"` with a `ui.model`, else none | the light all around (image-based): see [environment](#environment) |
| `tone_mapping` | `"neutral" \| "aces" \| "linear"` | `"neutral"` | how lit colours, which can be brighter than a display shows, are brought into its range: `neutral` (Khronos's PBR Neutral) keeps colours as the material says, rolling only highlights off to white, for products and anything whose colour must read true; `aces` is the filmic curve (more contrast, bright colours desaturating to white); `linear` clamps. Unlit meshes and the background show as they are |
| `exposure` | `Reactive<number>` | 0 | stops: each one doubles the light before tone mapping, −1 halves it |
| `antialias` | `boolean` | `true` | smooth edges: 4 samples a pixel (multisampling). `false` draws edges hard, its colour and depth a quarter of the memory. With it, highlights on fine curves are smoothed too (a surface's roughness widens where its normal turns faster than the pixels show), about 1% more GPU work |
| `label` | `string` | `"3D scene"` | its accessible name |

### orbit

`orbit = true` (or `{ auto_rotate, zoom, pan }`) gives the scene a model viewer's camera:

- Drag to turn the camera about its target; a flick coasts on and slows to a stop.
- Drag with the secondary (right, or two-finger click) or middle button, or with Shift, to pan: the scene follows the pointer. Shift-scrolling pans too. `pan = false` turns panning off.
- Scroll, or pinch on a trackpad, to move in and out (unless `zoom = false`).
- Focused (Tab, or a click), the arrow keys turn it 10° a press, Shift and the arrows pan, `+` and `-` zoom, and Home puts it back where it started.
- `auto_rotate` turns it on its own, in degrees a second.
- With reduced motion on (the system's setting, `ui.prefers.reduced_motion`), a flick stops where it's let go and `auto_rotate` holds still.

It all runs in Rust: coasting asks for frames only while it coasts, and a still camera draws nothing. A `camera.target` from a state or function moves the orbit's target as it changes; a pan stays until it does. Rust apps get the same with `zgx_3d::OrbitControls`.

### environment

An environment is light from every direction, as a room or the sky gives: each lit surface reflects it, sharply in polished metal and blurred in rough, and its diffuse light falls on surfaces by how they face it. It's what makes metal look like metal; without one, metal shows only the lights' highlights and the hemisphere's two colours.

- `"studio"`: built in, no file: a soft grey room with a large softbox above and in front, a strip light behind to one side and a fill panel to the other.
- A `.hdr` file (Radiance RGBE, equirectangular, as HDRI sites give them), from the script's directory: read and prefiltered off the main thread, shown once made, kept across reloads until the file changes.
- `{ src, intensity, rotation }`: `src` as above (default `"studio"`), `intensity` how bright (default 1), `rotation` degrees it is turned about the vertical; both `Reactive<number>`.
- `"none"`: no environment, as a scene without a model has.

It takes the place of hemisphere lights; directional and point lights still add theirs. Prefiltering makes a cube of its light at five roughnesses (128 texels a side, 0.5 MB on the GPU) and nine numbers for its diffuse light, once per environment: the studio is made once for the app.

## mesh

| Option | Type | Default | |
| --- | --- | --- | --- |
| `geometry` | `"box" \| "sphere" \| "plane" \| "cylinder" \| "cone" \| "torus"` | `"box"` | its shape |
| `size` | `number \| { number }` | 1 | a box's `{ x, y, z }`; a plane's `{ x, _, z }` |
| `radius`, `height`, `tube`, `segments` | `number` | 0.5, 1, 0.15, 32 | a sphere's, cylinder's, cone's or torus's (`tube`: its thickness) |
| `material` | `{ color, metallic, roughness, emissive, opacity, unlit }` | light grey, 0, 0.5 | `color`, `emissive`: `Reactive<Color>` (hex, names, `$tokens`); `metallic`, `roughness`, `opacity` 0 to 1; `unlit`: its colour as it is |
| `position` | `Vec3` | the origin | in its group's frame |
| `rotation` | `Vec3` | none | degrees about X, then Y, then Z |
| `scale` | `Reactive<number> \| Vec3` | 1 | one number for all three axes |
| `on_click` | `(hit: { x, y, z, distance }) -> ()` | none | a click on it: where, in the scene's frame, and how far from the camera. A press let go more than 4 points from where it began is a drag (orbiting) and clicks nothing |
| `on_hover` | `(over: boolean) -> ()` | none | `true` as the pointer comes over it, `false` as it leaves |

A `Vec3` is `{ x, y, z }` (each a literal, a state, a function or a binding) or a state or function of `{ x, y, z }`. The shape's own numbers (`size`, `radius`…) are literals: a shape is made once.

## light

| Option | Type | Default | |
| --- | --- | --- | --- |
| `kind` | `"directional" \| "point" \| "hemisphere"` | `"directional"` | sunlight going `direction`; a bulb at `position` reaching `range`; light from all around, `color` from above and `ground` from below |
| `color`, `ground` | `Reactive<Color>` | white; a sky blue and a brown for a hemisphere | |
| `intensity` | `Reactive<number>` | 1 | 3 is bright daylight for these materials |
| `direction` | `Vec3` | `{ -0.5, -1, -0.4 }` | which way a directional light travels |
| `range` | `number` | 10 | how far a point light reaches |

A frame shades with every directional and hemisphere light, and the four point lights nearest the camera's target. Lights are placed in the scene's frame, not a group's.

## group

`ui.group { position, rotation, scale, on_click, on_hover, …objects }` places its objects together: a model of several meshes turns as one. A click or hover on one of its meshes reaches the group, unless the mesh hears it itself.

What the pointer is over is found from the meshes' own triangles (both sides), the nearest one there, with no work on the GPU. A scene with no `on_hover` works out nothing as the pointer moves.

## model

`ui.model { src, fit, position, rotation, scale, on_click, on_hover }` shows a glTF 2.0 model: a `.glb`, or a `.gltf` and the files beside it (its buffers come from its own directory or below).

| Option | Type | Default | |
| --- | --- | --- | --- |
| `src` | `string` | required | the file, from the script's directory |
| `fit` | `number` | none: as the file has it | scaled to this many units across (its largest side), centred on its position |
| `animation` | `string \| number` | none | the clip it plays, round and round, by name or by its place in the file (from 1). It's posed in Rust each frame, with no script per frame. A name it hasn't is an error that lists the ones it has |
| `position`, `rotation`, `scale`, `on_click`, `on_hover` | | | as a group's: it places its meshes, and hears theirs |

```luau
ui.scene3d {
	w = "100%",
	h = 420,
	orbit = true,
	tone_mapping = "aces",
	exposure = 0.5,
	environment = { src = "studio", intensity = 0.8 },
	ui.model { src = "robot.glb", fit = 2, animation = "Walk" },
}
```

It's read off the main thread and shows once read; a file that can't be read is an error the script sees. It's kept read across reloads until the file changes, and a changed file reloads the script, as an image does. A model brings its default scene's nodes, its meshes, its materials' metallic-roughness factors, alpha modes (blended, or cut out by a cutoff), double-sidedness and unlit, and their base colour, metal and roughness, normal, emission and occlusion textures (PNG or JPEG); its clips move its nodes (translation, rotation and scale, by step, straight or cubic keys), its skins bend its meshes with their joints, and its morph targets blend them by its weights, its clips moving those too; a mesh's shadow and clicks follow its pose. A file that requires Draco or meshopt compression is an error that says so: its geometry can't be read yet. It needs zgx-script's `gltf` feature (zgx-run has it).

## Gotchas

- A shape's own numbers are literals. To change a mesh's size, change its `scale`.
- One sun casts shadows, point lights none.
- An environment replaces hemisphere lights: with one, a `kind = "hemisphere"` light adds nothing.
