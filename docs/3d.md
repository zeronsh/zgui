# 3D scenes in Rust

`zgx-3d` is a retained 3D world shown in any box: meshes in metallic-roughness materials, lights, a camera, and glTF models with their textures, animations and skins. A world draws a frame only when it changes, so a still scene costs nothing, and its pipelines and buffers are made with its first frame. In Luau the same world is [`ui.scene3d`](reference/3d.md).

```toml
[dependencies]
zgx-3d = { version = "0.1", features = ["gltf"] } # gltf: Model, and PNG and JPEG textures
```

## A world

A `World` holds objects (`Object::mesh`, or `Object::group` to place several as one), lights and a camera. Its `view()` is a [GPU view](gpu-views.md), so the box showing it clips, rounds, fades and hit tests like any other.

```rust,no_run
use zgx::compose::prelude::*;
use zgx_3d::*;

let world = World::new();
world.set_background(Some(0x10141b));
let group = world.add(Object::group());
let cube = world.add(Object::mesh(Geometry::cuboid(1., 1., 1.), Material::rgb(0x4a90e2).with(0., 0.35)).child_of(group));
world.add(Object::mesh(Geometry::sphere(0.35, 32), Material::rgb(0xd9a441).with(1., 0.3)).at([1.3, 0., 0.]).child_of(group));
world.add_light(Light::Directional { direction: vec3(-0.5, -1., -0.4), color: [1., 1., 1.], intensity: 2.5 });
world.set_camera(Camera::looking_at([0., 1.5, 4.], [0., 0., 0.]));

let view = gpu_view("A cube and a sphere", world.view()).w_full().h(320.);

// One change, one frame:
world.update(cube, |object| object.transform.rotation = Quat::from_euler(0., 0.5, 0.));
```

`Geometry` has `cuboid`, `sphere`, `plane`, `cylinder`, `cone` and `torus`, and `Geometry::new(vertices, indices)` takes your own triangles. Each geometry's meshes draw in one instanced call.

## Camera controls

`OrbitControls` answers a view's input as a model viewer does: drag to turn, right-, middle- or Shift-drag to pan, scroll or pinch to zoom (Shift-scroll pans), and, focused, the arrow keys turn (pan with Shift), `+` and `-` zoom and Home comes back. `zoom`, `pan` and `inertia` are fields to turn off. Hand it each event; its `Answer` says what happened.

```rust,no_run
use std::{cell::RefCell, rc::Rc, time::Instant};
use zgx::{compose::prelude::*, input::InputEvent};
use zgx_3d::*;

let world = World::new();
let controls = Rc::new(RefCell::new(OrbitControls::new(Orbit { distance: 4., ..Orbit::default() })));
world.set_camera(controls.borrow().orbit.camera(world.camera()));

let view = gpu_view("A model", world.view()).w_full().h_full().focusable(true).on_event({
    let world = world.clone();
    move |event| {
        let modifiers = match &event.event {
            InputEvent::KeyDown { modifiers, .. } => *modifiers,
            _ => event.pointer_modifiers(),
        };
        let mut controls = controls.borrow_mut();
        let answer = controls.handle(&event.event, modifiers, Instant::now());
        if answer.moved {
            world.set_camera(controls.orbit.camera(world.camera()));
        }
        if answer.taken {
            event.prevent_default();
        }
    }
});
```

`answer.coasting` says a flick is coasting on: call `coast(seconds)` a frame at a time until it returns `false`, setting the camera each time ([the `model` example](../crates/zgx-3d/examples/model.rs) does). Set `inertia = false` for reduced motion. `Orbit` alone is the arithmetic: `drag`, `zoom`, `pan` and `camera(base)`.

## Models

With the `gltf` feature, `Model::from_bytes` reads a `.glb` or a `.gltf` whose buffers are inline, and `Model::from_bytes_with` reads one whose buffers sit beside it. `World::add_model` adds it as one group to place, turn and scale. A model brings its default scene's nodes, its meshes (with smooth normals where it has none), its materials and their base colour, metal-roughness, normal, emission and occlusion textures, where those sit (a second set of texture coordinates, samplers' wrapping, `KHR_texture_transform`), its vertices' colours, its skins and its morph targets, and its lights (`KHR_lights_punctual`), each following its node. `Placed::cameras(&world)` gives its cameras where its nodes are, for `World::set_camera`.

To play its animations, place it with `World::place_model`, which keeps its nodes' objects. `Model::clips` lists its clips (`clip(name)` finds one), and `Placed::pose` poses one at any time, drawing a frame only if something moved:

```rust,no_run
use zgx_3d::*;

async fn play(world: World, frames: zgx::frame::FrameClock, bytes: Vec<u8>) -> Result<(), ModelError> {
    let model = Model::from_bytes_with(&bytes, |uri| std::fs::read(uri).ok())?;
    let placed = world.place_model(&model);
    world.update(placed.root, |object| object.transform.scale = Vec3::ONE * 2.);
    let Some(clip) = model.clip("Walk").cloned() else { return Ok(()) };
    let start = std::time::Instant::now();
    loop {
        frames.next().await;
        placed.pose(&world, &clip, start.elapsed().as_secs_f32() % clip.duration().max(1e-3));
    }
}
```

`cargo run --release -p zgx-3d --features gltf --example model -- FILE` shows a file and plays its first clip.

## Textures

`Texture::from_rgba8` takes pixels and `Texture::decode` a PNG or JPEG. `World::set_texture(id, Some(texture))` gives a mesh its base colour, and `World::set_map(id, map, Some(texture))` the rest: `Map::MetalRoughness`, `Map::Normal`, `Map::Emission` and `Map::Occlusion`. A normal map's frame comes from the screen's derivatives, so meshes need no tangents. A texture decoded from a file holds the file, and its decoded pixels only until a renderer has uploaded them. A scene without textures binds none.

## Skins

`Geometry::with_skin(joints, weights)` gives each vertex up to four joints, and `World::set_skin(id, Some(skin))` binds a mesh's object to a `Skin::new(joints, inverse_binds)`: objects as joints, up to `MAX_JOINTS` (256). The GPU places each vertex by its joints' matrices, so moving the joint objects bends the mesh, and its shadow and picking follow the pose. glTF models bring theirs.

```rust,no_run
use zgx_3d::*;

fn bend(world: &World) -> Result<(), &'static str> {
    let root = world.add(Object::group());
    let tip = world.add(Object::group().at([0., 1., 0.]).child_of(root));
    let bar = Geometry::cuboid(0.2, 2., 0.2);
    // Each vertex follows the joint at its end of the bar.
    let (joints, weights): (Vec<_>, Vec<_>) = bar
        .vertices()
        .iter()
        .map(|v| ([if v.position[1] > 0. { 1u16 } else { 0 }, 0, 0, 0], [1., 0., 0., 0.]))
        .unzip();
    let mesh = world.add(Object::mesh(bar.with_skin(joints, weights)?, Material::rgb(0xd9a441)));
    let inverse_binds = vec![Mat4::IDENTITY, Mat4::from_transform(vec3(0., -1., 0.), Quat::IDENTITY, Vec3::ONE)];
    world.set_skin(mesh, Some(Skin::new(vec![root, tip], inverse_binds)?));
    // Turning the tip's joint bends the bar:
    world.update(tip, |object| object.transform.rotation = Quat::from_euler(0.6, 0., 0.));
    Ok(())
}
```

## Light

`World::set_environment(Some(Environment::studio()))` lights every surface from all around, its reflections sharp in polished metal and blurred in rough. The studio is built in; `Environment::decode_hdr` reads a Radiance `.hdr` image (equirectangular), and `from_equirect` and `from_cube` take linear RGB. `intensity` brightens one and `rotated` turns it. Making one takes 11–16 ms, so do it off the main thread; the studio is made once for the app.

`World::set_shadows(true)` has the sun, the first directional light, cast soft shadows from opaque meshes. It costs a 2048 by 2048 depth map (16 MB) and a depth pass drawn again only when meshes or the sun move, not the camera.

`World::set_tone_mapping` says how lit colours reach the display's range: `ToneMapping::Neutral` (the default) keeps colours as the material says and rolls highlights off, `Aces` is the filmic curve, and `Linear` clamps. `World::set_exposure(stops)` doubles the light for each stop.

`World::set_samples(1)` draws hard edges at a quarter of the colour and depth memory; the default, 4, multisamples and smooths highlights on fine curves too, for about 1% more GPU work.

```rust,no_run
use zgx_3d::*;

let world = World::new();
world.set_environment(Some(Environment::studio().intensity(0.8).rotated(0.5)));
world.set_shadows(true);
world.set_tone_mapping(ToneMapping::Aces);
world.set_exposure(0.5);
```

## Picking

`World::pick(point, size)` says what a point of the view's box shows: a `Hit` with the `object`, the `point` on it in the world and its `distance` from the camera. It's found on the CPU from the meshes' triangles, so a world never picked costs nothing.

```rust,no_run
use zgx_3d::*;

fn clicked(world: &World, x: f32, y: f32, width: f32, height: f32) -> Option<ObjectId> {
    world.pick((x, y), (width, height)).map(|hit| hit.object)
}
```
