- **A window an item, from Luau** (zgx-script, zgx-run): `ui.windows(list, build, { key, on_close })` opens a window as an item appears in a list and closes it as the item goes, as `ui.each` does rows: a detail window per photo, a tab torn off into a window. A person closing one calls `on_close(item)`. `under_pointer` opens a window under the grab, on `ui.window` too.
