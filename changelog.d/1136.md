- **A canvas stroke no longer crashes a Windows app** (zgx-gpu): Direct3D 12 compiling the canvas shader overflowed the stack inside FXC, Windows' shader compiler, so an app's first chart line, sparkline or stroke crashed it on a machine that hadn't cached the shader yet. Filled areas, whose shader FXC can't compile, now rasterize on Windows; strokes still draw on the GPU.
