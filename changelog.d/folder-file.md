- **A folder's files can be shown and handed on** (zgx-script): `folder:file(path)`, and `folder:list(path, { files = true })`'s entries, give a `File` that `ui.image`, `ui.read_file` and `drag_export` take as they do a dialog's, so a browser shows thumbnails and drags files out to Finder. A plugin with the grant can show the files it was given.
