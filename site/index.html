01 / SAME WORK

Matched UI, matched inputs

100,000 fixed-height rows, viewport virtualization and deterministic streaming text. Each framework runs idle, streaming, scrolling and combined modes.

02 / REPEATED TRIALS

36 separate process trials

Three repeats per framework and workload. Each requests 20 seconds, with the first 5 seconds excluded. Framework order rotates between repeats.

03 / THIS ENVIRONMENT

Linux, software rendering

Mesa llvmpipe on Xvfb. LP_NUM_THREADS=4 per Mesa pool, not per process. This shared-host run is not a hardware-GPU or macOS result.

04 / WHAT IT DOESN’T SAY

Updates are not frames

Active runs must deliver 58–61 logical updates per requested second. That checks work completion, not presented FPS or latency. RSS excludes separate GPU memory and other processes.

Reproducible by design.

Source revision, binary identities, protocol and acceptance are recorded with every run.
